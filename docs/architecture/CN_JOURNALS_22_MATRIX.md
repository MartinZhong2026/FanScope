## 结论与建议

1. **可以先行的 4 本（E）**：官网平台 3 本 + Crossref 1 本。它们复用现有解析器与 Crossref 适配器，是第一批接入调度的对象，完成后进入 B，经过 7 天观察期后进入 A。
2. **"官网 `/CN/` 平台"覆盖面最大**：人口研究、社会、社会建设已核实；社会学评论、公共管理与政策评论使用同一平台（中国人民大学系），证书修复后就能直接复用。**一个平台适配器最多覆盖 5 本。**
3. **ajcass 平台**涉及 5 本（中国人口科学、社会学研究、社会发展研究、妇女研究论丛、残疾人研究）。其中社会学研究有反爬验证（C），其余受网络与摘要可得性制约。题录适配器值得写，摘要需单独研究。
4. **11 本处于 D，主要是网络路径问题（TLS 重置）与证书问题。** README 记载生产主机在曼谷；如果它同样位于中国大陆境外，很可能遇到相同的重置。这决定了全部 22 本的可行路径：
   - **方案一**：在 O2 盘点时从生产主机运行探测脚本；如果能连通，D 中的多数会转为 E 或 E-。
   - **方案二**（如果生产主机同样被重置）：采用**授权聚合渠道**（例如国家哲学社会科学文献中心，或学校已订阅数据库提供的授权批量导出或接口），用一个 `authorized-export` 适配器覆盖剩余期刊，而不是维护 11 个脆弱的站点抓取器。**需要你提供具体渠道名称及其自动化与存储条款。**
   - **不采用**：降低 TLS 校验、绕过 JS 验证、在未获授权的情况下抓取数据库页面，或使用未经评审的境内代理。
5. **数量承诺**：本轮可以如实承诺的是"22 本全部进入调度登记、逐刊状态可见、失败原因可查"。达到 A 的数量取决于上面第 4 点的结果，不预设 22/22。

**每个适配器的完成标准**：

- 用脱敏的真实页面夹具做契约测试；
- 通过身份校验（ISSN、刊名）；
- 日期精度如实记录；
- 中英文摘要来源可追溯，缺失时记录原因；
- 模板变化时把来源标为降级；
- 通过交付计划 §9-A 的全部用例；
- 生产上线后，每刊抽样 20 条与官网人工对账；
- 通过 7 天观察期后才可标为 A。
