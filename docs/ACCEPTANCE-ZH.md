- [x] Crossref 增量轮询完整流程（使用本地模拟服务）：首次写入5篇，二次重复扫描无新增。
- [x] RSS/Atom 常见字段解析的模拟样例测试。
- [x] AI 样本量缺乏逐字证据时写入 null 的测试。
- [x] 管理员密钥未提供时拒绝写接口测试。
- [x] 没有邮件 API 配置时返回明确 503，不会假装邮件已发出。
- [x] 邮件验证、同文章不重复提醒、确认退订流程（Resend API 使用本地 mock）。

- [ ] 未在实际 Cloudflare Pages 或 Nginx 服务器部署。

## 你部署后必须逐项验收

1. `https://fanscope-api.<域名>/api/health` 返回 `status:ok`。
2. `https://<项目名>.pages.dev` 打开，页眉显示 **API 已连接**；没有 CORS、SSL、Mixed Content 错误。
3. 「监测健康状态」里英文期刊至少一次 `last_success` 非空，`last_error` 为空或可解释。
4. 重启 Docker 容器后已有论文和邮件订阅不丢失。
5. 同一 DOI 在重复扫描后只对应一条论文记录。
6. 前端按照「全部 / 国内 C 刊 / 英文期刊」切换，列表与趋势图数字真实变化；没有论文时显示空态。
7. 中文期刊 RSS 未接入时清楚提示「待配置」，不会出现虚假“已同步”标识。
8. DeepSeek 缺少 KEY 时不写入伪造的样本量和研究方法；填 KEY 后仅对有摘要文章尝试分析。
9. 邮件服务配置完成后，在订阅页填真实邮箱，收到验证邮件，点击后开始接收；历史回填不得群发即时提醒。
10. 检查同一新 DOI 在重复扫描中不会重复推送；执行退订确认后不再收到邮件。
11. 390px 手机宽度下导航、列表和表单可用，页面不出现大面积横向溢出。
12. 抽取至少 30 篇真实文章人工核对 AI 输出字段，包括样本规模、研究设计、一手/二手数据分类及证据片段。

## 线上必须定期巡检

- 每周：看 `/api/system-status` 是否存在频繁 Crossref HTTP 429 / 503、缺少检查点或 RSS 格式变化。
- 每周：验证最近一份邮件送达时间，查看退信和垃圾邮件比例。
- 每月：备份 SQLite 和更新 `journals.json`，检查 ISSN 与新在线预发表论文的覆盖率。
- 每次 Node 版本升级：运行 `npm test`，核查内置 SQLite 实验性接口兼容性。
