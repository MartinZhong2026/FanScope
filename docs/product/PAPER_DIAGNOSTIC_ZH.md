# Paper Diagnostic（论文诊断）· D1/D2 第一版

状态：代码与自动化验收已完成；**生产默认关闭**（`FANSCOPE_DIAGNOSTIC_ENABLED` 未设置时所有 `/api/diagnostic/*` 返回 404，页面显示“尚未开放”）。

## 用户流程（真实页面）

课题组登录 → 工作台右上角“论文诊断”（`/lab/diagnostic.html`）→ 上传 PDF / DOCX / Markdown / TXT（≤10MB，不支持扫描版）→ 阅读并勾选授权说明 → 开始诊断 → 查看报告 → 可共享、重新诊断或删除。历史记录列在左侧。

报告分三部分：
1. **稿件事实**：研究问题、理论、假设、数据、方法、结果、结论，每条都附原文摘录，并经服务端逐字核对；无法在原文中找到的条目会被剔除并计数。
2. **问题与修改建议**：按 严重 / 重要 / 次要 排序，包含证据摘录、审稿人可能的追问和可执行建议。没有可核对原文的条目会标注“推断”。
3. **分维度检查**：按论文类型给出。定量研究检查变量、样本、模型、推断、因果表述、稳健性；定性研究检查抽样、资料收集、分析、反身性、诠释。

## 引擎

| `FANSCOPE_DIAGNOSTIC_PROVIDER` | 说明 |
| --- | --- |
| `rules`（非生产默认） | 关键词规则演示引擎，不调用任何外部服务；报告明确标注“演示模式”，不冒充 AI |
| `deepseek` | 真实 AI 引擎，分两步（结构识别 → 诊断），稿件全文作为稳定前缀以利用 DeepSeek 上下文缓存。需 `DEEPSEEK_API_KEY`；每人每日上限 `FANSCOPE_DIAGNOSTIC_DAILY_LIMIT`（默认 5） |
| 未设置（生产） | `none`，诊断请求返回 503 |

授权按引擎记录：对规则引擎的同意**不能**用于 DeepSeek，切换引擎后须重新同意。

## 权限与隐私（服务端强制）

- **可访问者**：上传者本人；上传者显式共享的成员；与上传者在 `dx_advisor_links` 中有指导关系的导师。其他人（包括无关导师和管理员）一律 403。
- **操作权限**：诊断、授权、共享、删除只有上传者本人可做；导师关系由导师或课题组管理员维护。
- **保留期限**：
  - 原稿文件与提取文本保留 14 天，报告保留 90 天，从上传时计。
  - 每次读取都检查期限，过期返回 410。
  - 物理删除由 `purgeDue()` 执行（每次诊断请求顺带执行，另有每小时定时器），可重复执行。
  - 报告到期后，标题和文件名也一并清空。
- **主动删除**：立即删除文件、文本和全部报告，共享对象同时失去访问权限。诊断进行中被删除时，本次结果丢弃并记为 `cancelled`。
- **日志**：只记录 id、引擎、错误码和耗时，不记录正文、提示词或模型输出；测试会检查日志中不含稿件句子。
- **浏览器安全**：页面使用独立的严格 CSP（`web/_headers`，`/lab/diagnostic*`），不使用内联脚本。
