# FanScope Lab v1.1 人工验收清单

操作均使用 **合成测试内容**，不要使用真实群聊或未公开访谈来做首次上线验证。

- [ ] 原学术情报首页可打开，监测、邮件订阅和统计仍能访问；点击侧边栏“科研项目与 AI 组会更新”进入 `/lab/`。
- [ ] 未登录不能读取 `/api/lab/projects` 和 `/api/lab/manuscripts`，后端返回 401。
- [ ] 导师登录，创建项目、论文、两名组员，以及一名 Lab Admin。
- [ ] Lab Admin 可创建其他成员、编辑公共项目，却不能查看普通同学的论文私密备注。
- [ ] 项目管理员只能修改获授权的项目，不能修改其他项目。
- [ ] 组员 A 登记论文，组员 B 能看到题目、作者、阶段，却不能读取 A 的私密备注、下一步及私人历史。
- [ ] 组员 A 在 Members 中更新“近期实习中”，组员 B 无权查看具体描述，导师有权查看。
- [ ] 将 `api/test/fixtures/sample-meeting.docx` 和 `.pdf` 导入 `/lab/`，文件可保留与下载；无 DeepSeek Key 时应显示需重试，而不是虚构更新。
- [ ] DeepSeek 配置后，用包含现有项目名称和明确进展的合成 Word 进行一次真实处理；检查原文证据必须来自上传文本。
- [ ] 查看待审核建议，未点击批准前不应改变项目或论文状态。确认后出现时间线记录；拒绝则不改变状态。
- [ ] 上传组会记录的学生如果不是某篇论文的负责人，不能看到论文具体建议。对应作者和导师从“分配给我的待审核建议”中处理。
- [ ] 原研究数据库页面仍为灰色入口，不上传此前提供的课题组原始数据。
- [ ] 桌面 1440px 与手机 390px 页面能登录、浏览项目、论文、上传与审核。手机端导航可横向滑动。
- [ ] 升级服务器前已备份 Docker `fanscope_data` 数据卷，升级后新旧数据均可读取。
