本轮日期研究窗口为 2023-10-27—2026-10-26。平台导航显示年份，只证明存在入口，不能证明每一期、每篇均完整。搜索索引和页面有缓存差异，以下“观察到的期号”不代表实时最新出版期号。平台全历史“发文量”没有用于推算三年论文数。

## 平台调查：可浏览、可批量获取和可再展示分别判断

### N：国家哲学社会科学文献中心（NCPSSD）

四本重点刊物均有按确切刊号匹配的公开目录；这些页面有当前期题名及往年导航。它比精确 ISSN 的 Crossref/OpenAlex 查询更能解释这些中文刊物的实际可见目录覆盖。公开浏览入口见[逐刊表](remaining-19.md)。

平台工作人员介绍的建设实践明确存在机构镜像系统，以及元数据嵌入、集成和数据接口合作。这说明“机构合作取得元数据”是一条有依据的路线；文章没有发布面向任意用户的匿名开放 API、通用采集许可或再分发许可证。[平台建设实践，2023](https://wxysjxb.ajcass.com/Admin/UploadFile/Issue/201902190001/2023/4/20230406092003WU_FILE_0.pdf)

建议由课题组或学校图书馆向文献中心申请 19 刊的**元数据合作/合法题录导出**，优先四刊，确认实际可提供的年份、字段、更新时滞、缺期、批量权限和 FanScope 展示范围。[当前门户](https://www.ncpssd.cn/)及移动目录页页脚列有 `ncpssd@cass.org.cn`、010-85195335。本轮没有发送邮件、申请账号或联系第三方。

限制：免费阅读、可下载按钮和机构访问均不能自动视为允许建立另一个可搜索数据库。没有调用未公开接口，没有借用登录态或下载全文。部分 `.org`/`.cn` 页面超时；另有搜索缓存，不能据此承诺实时覆盖。

### V：维普公开目录与机构题录服务

公开期刊页能核对 ISSN、主办方、年份/期次、部分作者和页码，部分页面显示单期条目数；本轮还发现页面文本提取时题名可能缺失，因此不能直接将提取结果当作可导入的完整元数据。题录中也混有封面、编委会、总目录、征订启事和书评，必须逐类审查。

维普公司网站列有“元数据服务”，是可询问的正式合作方向；当前可见信息没有给出这 19 本的开放下载包、免费批量 API 或 FanScope 使用许可。[维普公司产品入口](https://www.vipinfo.com.cn/?from=index)

维普**智立方**的协议说明机构线下签约、题录格式导出，并对未授权程序采集、复制、展示等行为设限。该协议适用于智立方，**不能直接套用于维普主站或维普 OA 的全部页面**；主站/OA 的相应产品条款及本次再展示权限仍需单独确认。[智立方用户协议，第2.2、4—7、8节](https://zlf.cqvip.com/help/UserAgreement.html)、[OA 平台协议](https://oa.cqvip.com/userAgreement)

建议图书馆核查现有采购合同是否允许所需数量的题录导出、自动化和内部检索展示；不足则申请专项元数据授权。不要将“导出题录”按钮解释为不限量批量许可，也不要用普通账户模拟批量爬取。目录页客服入口列有 `service@cqvip.com`、400-638-5550；本轮未联系。

### W：万方正式 API / 合同内题录导出

万方有公开的选题 API 文档。文献查询接口要求 `X-Ca-AppKey` 和基于 AppSecret 的签名，响应结构含刊物 ID、期刊名、作者、年份、卷期、DOI、摘要和分页总数。这是**正式需凭据的 API**；该文档不证明能按 19 刊完整导出三年数据，尤其需要确认精确刊号/刊物 ID 过滤、覆盖及许可。[万方选题 API 官方文档](https://topic.wanfangdata.com.cn/api.html)

公开目录样本也显示批量选择和导出入口，例如[人口与经济 2023/6](https://sns.wanfangdata.com.cn/perio/rkyjj?issueNum=6&publishYear=2023&tabId=article)。是否需登录、机构采购及导出额度，需按具体产品合同确认。本轮没有申请/使用 Key，没有调用需认证接口，没有执行导出。

建议先向万方提供 19 个 ISSN 和三年窗口，请其返回**每刊每期覆盖清单与元数据总数**，确认是否支持一次性交付 CSV/RIS/XML；不能只依据“海量资源”或响应示例承诺覆盖。

### E：出版社、主办方和高校期刊平台

中国社会科学网、社科院期刊平台、人大期刊平台、CNKI 期刊门户及中国软科学官网都提供了有价值的目录证据。优先询问刊方可否直接交付题录、JATS/XML 或 CSV，避免每刊维护一套脆弱抓取器。

有 RSS 说明的刊物可作为**后续增量**候选，但 RSS 的当前订阅范围不等于三年历史批量授权；本轮没有确认 19 刊存在统一 OAI-PMH、完整 RSS 历史或公开 JATS 数据包。期刊门户内部请求所需 TOKEN 不是公开 API 凭证，不追查或绕过。

## 对此前来源判断的修正

1. 《中国社会科学》在中国社会科学网有实际期目索引，文献中心有更早年份导航；不能把某个错误路径 403 解释成无公开目录。[刊方索引](https://www.cssn.cn/dkzgxp/zgxp_zgshkx/)
2. 《公共管理学报》公开门户显示 2023—2026 年卷期和当期题名。此前某个入口的无效 TOKEN 只说明该请求方式不可用，不代表公开门户整体不可浏览。[公开门户](https://gggl.cbpt.cnki.net/portal/journal/portal/client/index)
3. 《治理研究》当前 ISSN 为 **2097-5406**。未来需建立历年刊号映射及生效区间，不能只拿旧号 `1007-9092` 搜索后宣布无数据，也不能在未核刊号沿革时无条件并库。[ISSN 中心现行记录](https://portal.issn.org/resource/ISSN/2097-5406)
4. 《中国软科学》当前 ISSN **1005-0566**，国家图书馆 ISSN 清单和刊方页相互支持；此前 `1002-9753` 的查询结果不能作为本刊无覆盖的充分证据。后者在 ISSN 记录显示为另一题名，仍需核实沿革，不能直接列为现行别名。[国家图书馆清单](https://www.nlc.cn/web/yejiefuwu/newtsgj/newissn/cxissn/numcx/20101118_11435.shtml)、[刊方](https://www.cssm.com.cn/zgrkx/home)

这些是研究结论，**本轮没有更改生产或本地来源配置，也没有以新刊号重跑采集**。历史验收文档保留当时观察，后续判断应结合本报告。

## 第二批执行计划

以下是下一批实施次序，本轮停在研究和本地归档，不开始新的大规模开发或回填。

| 阶段 | 具体动作及交付 | 放行条件 |
|---|---|---|
| 1. 四刊授权清单 | 以文献中心元数据合作为共同主线；同时向四刊编辑部/图书馆核查可授权 CSV、RIS、XML 或接口。记录许可人、产品、刊号、年份、字段、展示范围、额度、到期日 | 书面许可或适用的明确开放条款；如需购买/正式机构申请，交由用户/图书馆办理，不自动付费或联系 |
| 2. 每刊一期样本 | 每刊取得一个最近完整期，人工逐条核对原题、作者、卷期、页码、日期精度、原链接，剔除非论文，并核对导出总数 | 四刊分别验收；来源缺字段保持空，不伪造摘要/日期；单刊失败不阻塞其他刊 |
| 3. 四刊 180 天 | 取得近 180 天逐期清单后，复用 `api/src/chinese-ingestion.mjs` 和现有授权 CSV 入口导入本机独立 SQLite；执行前复制新批次库，保留当前 349 条基线 | 对账包含应有期、缺期、发现/排除/去重/新增/更新数；第二次导入新增应为 0；四刊入库且可追溯后覆盖才从 3/22 提到 7/22 |
| 4. 其余 15 刊 | 优先一个平台授权多刊；其次人大期刊群（社会学评论、社会建设、公共管理与政策评论），再按逐刊证据补齐其余刊。先抽一期再180天 | 每刊独立满足授权、身份和期目对账，不以论文多的已接入刊抵消未接入刊 |
| 5. 条件性历史扩展 | 只有获得历史范围许可且 180 天对账通过，才另立计划扩展三年；优先让提供方一次交付文件和每期控制总数 | 不自动继续本轮已暂停的三年回填；保留月份/年份精度和缺失字段；无摘要不进入需摘要支撑的方法分析 |

四本优先顺序建议同时准备授权材料，样本验收按《中国社会科学》→《社会学研究》→《管理世界》→《公共管理学报》推进，不因第一本等待授权而停止其他三本沟通材料准备。各刊首选和备用渠道见逐刊表。获得正式接口之前，**授权 CSV 导入是现有代码可执行的最短路线**，不是开发第二套引擎。

未来若必须新增接口适配器，也只接入现有引擎；以合同限速为准，起始预算建议并发 1、每刊一期试点、每日最多 100 次请求（服务方更严则从严），遇登录、验证码、403、429 或权限拒绝即停止相应来源并记录。服务器错误在许可预算内退避，不通过换域名、代理、账号、指纹或令牌规避限制。

验收必须同时报告期刊覆盖率、逐期完整率、实际论文数、缺期/延迟、来源授权状态、字段完整率和去重结果。尚未取得许可证和控制总数之前，本报告不承诺能够导入多少篇。
