# FanScope v1.2+ — 本次交付说明

**代码基线**：用户上传的 GitHub Draft PR #1 版本 `903f37e8a8ab95cebb2825dffede170f45d9deed`。保留原数据库结构、Crossref 可恢复扫描、OpenAlex 可选接口、DeepSeek 证据提取、论文表/ExcelJS、期刊候选、ECharts 与权限边界。

## 新增与修复

1. **手机端功能入口首页**：≤760px 默认两列 6 张入口卡片（最新论文、研究趋势、期刊画像、AI 简报、科研项目、论文进度），快捷工具包括会议导入、邮件通知和监测状态。图标使用内嵌 SVG，不依赖在线图标服务。桌面保留 Sidebar。导航深链接 `/#/feed`、`/#/trends` 等，支持返回按钮与浏览器历史；页面刷新能够恢复目标模块。
2. **移动 Lab**：≤950px 隐藏原多行菜单，增加简洁顶部返回入口和四项底部导航；支持 `/lab/?view=projects`、`?view=manuscripts`、`?view=documents`，未登录先登录再进入目标模块，浏览器前进/后退切换模块。
3. **Meetfolio 文件互通 A 方案**：原 PDF/DOCX 之外新增 `.md` 和 `.txt` UTF-8 文件导入（前端与后端双重检查扩展名/MIME）；文件不超过 512KB，提取至少 40 字；原文私有保存、原生证据审核和 AI 项目/成员建议沿用 FanScope 原逻辑。提供“Meetfolio 导出”来源选项。**不声称已经完成 WebSocket/实时录音/双向账户同步**。
4. **验证**：新增无依赖移动模板单元测试、TXT/Markdown 文档处理回归案例和离线浏览器响应式检查。保留原 v1.2 CI、36 项测试及原图表。

- **JCR：** 20 本英文期刊候选尚待通过 Clarivate/JCR 授权目录核验年度学科 Q1，不自动写入 `verified`。

- **邮件：** Resend 依赖经验证的发件域名及真实投递测试；未将密钥写入公开代码。
