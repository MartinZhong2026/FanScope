## P0 修复前后证据

- 交接诊断的原问题是 `Crossref page limit (4) exceeded`，索引重收录的2016旧文排在最新发表区。该诊断不是本次新测得的生产统计。
- 当前离线测试对 **JMIR与Social Science & Medicine分别模拟550项**，配置仍为 `maxPages=4`，两刊均读完6页、计数550并完成窗口。预算在窗口边界生效，未把第4页当终止点。
- 当前窗口完成前不前移窗口起点；异常保留失败游标，过期时只重放该固定窗口，重复DOI不会新增。两窗口602条也完整通过。
- 真实Crossref只读参数探测先得到400（不接受毫秒和Z），改为官方秒级日期格式后得到200。**这仅证明请求参数合法，不声称生产两刊已经全量同步完成。**
- 文章API排序与邮件防历史轰炸由真实SQLite/HTTP测试验证。未调用生产扫描，也没有发送真实通知。

2. OpenAlex的服务端补全、DOI/ISSN核对、缓存、速率与每日上限已实现并mock测试；默认关闭。当前套餐、权限、条款及实际收费须由运营者确认，真实账号联调未做。现有自动监测仍以已配置的Crossref/RSS为主，OpenAlex由管理员有界触发。
3. 生产1590篇、JMIR/SSM真实全量窗口恢复、真实出版社页面标题/DOI解析抽样、校园VPN访问、邮件DNS与真实送达均需人工上线后验收。未访问生产数据验证1590这一交接数字。
4. 实际研究方法结论与候选研究机会需人工抽样检查。仅摘要，不代表全文审查；旧版AI结果保留但不算新版逐字段证据覆盖。
5. Excel近似题目显示冲突线索，规范标题重复自动跳过；不自动模糊合并。用户可先修正共享表再导入。项目/申请/经费工作表不自动导入，本版未提供项目Excel导入预览；专报独立模块、通用资料库、OCR/ASR、基金公告继续留待后续。
6. 文件记录可关联已授权科研交流文档；未扩展为通用任意格式科研文件管理。原始文档每次新上传生成独立不可覆盖记录，暂未做显式父子版本树。
